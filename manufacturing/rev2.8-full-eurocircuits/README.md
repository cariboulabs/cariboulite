# Five CaribouLite Full Rev 2.8 boards — quotation package

Prepared 2026-09-12 from the original files in `hardware/rev2`.
**Ready for technical review and quotation upload; not released for manufacture.**

The PCB contains **661 blind vias between copper layers 1–2 and 736 between
layers 3–4, all with 0.1016 mm specified holes**. Eurocircuits must confirm it
can reproduce these and the original stack-up before a price is accepted.
The ordinary four-layer pooling defaults must not silently replace this build.

Read `technical-review.md` and give `manufacturer-questions.txt` to the technical
reviewer. They cover:

- Blind-via process and stack-up compatibility.
- J1's corrected placement centre, with its original side/rotation retained for review.
- Exact-part sourcing, component orientation, PCB finish, and manufacturer DFM warnings.

U25's source-field conflict is resolved: use exact MPN
`SG-8018CG 125.0000M-TJHSA3`. The `TJHPA3` description/PnP text is retained in
the audit as original-source evidence but is not an approved substitution.

J7's population is also resolved: fit exact MPN `CONUFL001-SMD-T`. It is
present in the BOM, PnP, assembly drawing and physical reference board, and is
outside the schematic's DO NOT PLACE boundary. R25, C108 and C122 remain DNP,

absent from the BOM/PnP, and absent from Jan's physical reference board.
The shield drawings remain under `originals/` only as unmodified source evidence;
shield supply and fitting are outside the reproduction and quotation scope.

No design changes or automatic component substitutions are authorized. Quotation
assumptions must be shown explicitly. This package does not authorize an order.

## Package contents and reproducibility

`originals/` contains byte-for-byte copies of the Full assembly files, shared
PCB data, Full schematic and shield DXFs. The ISM variant is excluded.
`source_manifest.json` and `.md` inventory every source, including those exclusions.
`SHA256SUMS` covers all delivered files except the outer archive and itself.

`validation/` contains machine-readable drill counts, layer mapping, BOM/PnP
reconciliation, pad-alignment residuals, stack-up extraction and a per-component
placement transformation audit. `procurement/bom-audit.csv` retains original
MPNs/comments and spreadsheet row numbers, with five-board quantities separately.

To regenerate in the original repository:

```sh
python3 -m venv /tmp/cariboulite-mfg-venv
/tmp/cariboulite-mfg-venv/bin/pip install -r manufacturing/requirements.txt
/tmp/cariboulite-mfg-venv/bin/python manufacturing/build_rev2_8_package.py
```

The copy of that script in `tools/` is for provenance; run the repository's
`manufacturing/build_rev2_8_package.py` against its `hardware/rev2` tree.
The script checks quantities, drill counts, source copies and all 210 original
pad-reference alignments. It leaves original design files untouched. ZIP entries
use fixed timestamps and sorted names for reproducibility. The manually reviewed
documents are included unchanged, not regenerated by the script.

To verify an unpacked package on Linux:

```sh
sha256sum -c SHA256SUMS
```
